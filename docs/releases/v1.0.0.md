# MacroCode v1.0.0 — Release Notes

**Date:** November 22, 2026
**Previous Version:** v0.2.3

---

## 🎯 Overview

MacroCode 1.0.0 is the first stable release: a local-first, bring-your-own-key
AI terminal for Linux, Windows and macOS. It combines a terminal-style chat
with an approval-first coding agent, project snapshots, built-in Git and MCP
tools — with no account, no server and no telemetry.

## ✨ Highlights

### Chat and providers
- 12 providers: Anthropic, OpenAI, Google Gemini, Ollama, OpenRouter, DeepSeek,
  xAI, MiniMax, Kimi (Moonshot AI), GLM (Zhipu AI), NVIDIA and EVREN LLM.
- Live model discovery plus [models.dev](https://models.dev) metadata for
  context limits, vision/reasoning capabilities and pricing.
- Streaming responses, native tool calling, prompt caching, per-turn token and
  cost metering, and `/tokens` reporting.

### Agent mode
- Point the agent at a project folder with `/root`; it can read, search, edit
  and run commands.
- **Approval-first:** every write and shell command goes through an approval
  card. `exec` is never auto-approved.
- Workspace root jail, symlink-escape protection, blocked/secret paths, and
  restricted `rm` and system directories.
- MCP servers over stdio or HTTP, plus sub-agents and plan/todo tools.

### Project safety and Git
- `/snapshot`, `/snapshots` and `/restore <id>` with the whole workspace
  (secrets and ignored directories excluded).
- A safety snapshot before every restore; agent edits keep an undoable backup.
- Git panel and `/git` commands: status, diff, commit (optional AI message),
  history, branches and fetch/pull/push. Mutations ask for confirmation.

### Desktop experience
- Terminal-native UX with slash commands, command history and keyboard-first
  navigation.
- Five UI languages: English, Türkçe, Deutsch, Français, Español — switched
  instantly without restart.
- Sessions in local SQLite with JSON export/import; works offline.

## 🔒 Security notes

- API keys are stored locally in the app-data directory (`keys.json`); on Unix
  the file mode is `0600`. Keys are only sent to the provider you configured.
  **Keys are not encrypted at rest** and are not stored in the OS keychain yet.
- CSP restricts network access; custom endpoints and MCP requests go through
  the Rust proxy.
- Updates are verified with the Tauri updater public key. Windows Authenticode
  and Apple Developer ID signing are applied when the release secrets are set;
  unsigned builds may trigger SmartScreen/Gatekeeper warnings.

## ⬆️ Upgrading

- Linux AppImage installs update automatically; `.deb` / `.rpm` users are
  directed to the release page.
- Windows NSIS installs update automatically (`passive` mode).
- macOS builds are supported; updater metadata includes both `darwin-x86_64`
  and `darwin-aarch64`.
- Sessions and settings remain local; the SQLite schema is migrated automatically
  on first launch. Export a JSON backup first if you want an extra safety copy.
