# MacroCode v1.0.1 — Release Notes

**Date:** November 23, 2026
**Previous Version:** v1.0.0

---

## 🎯 Overview

MacroCode 1.0.1 moves the project to its new home,
[`Geblkc/MacroCode`](https://github.com/Geblkc/MacroCode). No behavioural
changes: this is a maintenance release that points every link, badge and the
in-app updater at the new repository.

## 📦 Distribution

| Platform | Package |
|---|---|
| 🐧 Linux (AppImage) | `MacroCode_1.0.1_amd64.AppImage` |
| 🐧 Debian / Ubuntu | `MacroCode_1.0.1_amd64.deb` |
| 🐧 Fedora / RHEL | `MacroCode-1.0.1-1.x86_64.rpm` |
| 🪟 Windows (NSIS) | `MacroCode_1.0.1_x64-setup.exe` |
| 🪟 Windows (MSI) | `MacroCode_1.0.1_x64_en-US.msi` |
| 🍎 macOS (universal) | `MacroCode_1.0.1_universal.dmg` |

## ⬆️ Upgrading

This is the first release published under the new repository
[`Geblkc/MacroCode`](https://github.com/Geblkc/MacroCode). Install 1.0.1 from
the [releases page](https://github.com/Geblkc/MacroCode/releases/latest); later
versions update in place again (Linux AppImage, Windows NSIS, macOS).

Sessions, settings and API keys are unchanged and stay local.
